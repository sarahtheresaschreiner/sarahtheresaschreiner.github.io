    urls and views

    Urls

    are the patterns from the webpage -> You define where they'll lead to in the views

    urlpatterns = [
    path("", views.index, name="index"),
]

    Views

    returns what should be shown and if some action is happening it is defined in there

    def index(request): # the index-view
    return HttpResponse("Hello, world. You're at the polls index.")

    Include another app

    • If you have an app, you need to connect it in the urls.py file of the main app:
    urlpatterns = [
    path("polls/", include("polls.urls")),
    path("admin/", admin.site.urls),
]

    - add it to the settings file: "polls.apps.PollsConfig",

    Models

    Models are the classes, that are in your database. A class is a table basically and it has columns: 

    class Question(models.Model):
    question_text = models.CharField(max_length=200)
    pub_date = models.DateTimeField("date published")

    After changing a model you need to make migrations: py manage.py makemigrations polls
